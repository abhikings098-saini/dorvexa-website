# Dorvexa Digital Agency Website

A responsive, static website made with HTML, CSS and JavaScript. No frameworks, paid hosting, database or build tools are required.

## Run locally
1. Keep `index.html` and the `assets` folder together.
2. Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository, e.g. `dorvexa-website`.
2. Upload `index.html`, `README.md`, and the complete `assets` folder (including all 3 images).
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait a little; GitHub will show your published website link in the Pages section.

## Edit the website
- Main text and sections: edit `index.html`.
- Logo image: replace `assets/dorvexa-logo.jpg` with your logo, keeping the same filename.
- Main banner: replace `assets/meta-ads-banner.jpg`.
- Services image: replace `assets/meta-ads-services.jpg`.
- WhatsApp link: search in `index.html` for `https://wa.link/9hx5yb` and replace every occurrence if your link changes.
- Package names/prices/features: find the `id="packages"` section. Example prices are placeholders; confirm your actual prices and deliverables before publishing.
- Colors: edit the CSS variables near the top of the `<style>` block (`--bg`, `--blue`, `--cyan`, `--gold`).
- Business name: search for `DORVEXA` and replace it if needed.

## Important
This is a front-end static site. It does not process payments, collect form submissions, or manage customer accounts. WhatsApp buttons open the supplied WhatsApp link. Advertising spend is separate from agency service fees. No results are guaranteed.
